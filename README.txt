PASTA DE LIVROS DIGITAIS

A pasta está vazia de propósito. Para ativar o leitor integrado de um livro,
coloque aqui apenas um EPUB cuja disponibilização pela internet esteja autorizada.

Para o título de demonstração Diário de um Banana 20: Festa Insana, o código
procura especificamente por:

    diario-banana-20.epub

Se o arquivo existir, a página correspondente abre o EPUB automaticamente no
navegador. Arquivos em static/ são acessíveis publicamente no site publicado,
portanto confirme a autorização para distribuição online antes de adicioná-los.
